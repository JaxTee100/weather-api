🌤️ Weather API
A Node.js and Express API that fetches weather data from Visual Crossing Weather API and caches responses in Redis for faster performance.

🚀 Features
Fetches real-time weather data
Caches responses in Redis (30 min)
Optimized for speed and efficiency
📡 Usage
GET /weather/:city → Returns weather data for a city
Cached responses reduce API calls
🛠️ Tech Stack
Node.js, Express, Axios, Redis
🏗️ Setup
Install dependencies → npm install
Set up .env file with API key
Start Redis → redis-server
Run the app → npm start
